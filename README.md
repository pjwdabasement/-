# SCARLET OATH — 축제 체험 부스판 (챕터 2 · 웃음의 마을)

체험자가 **기본 공격 / 스킬 1 (Q) / 스킬 2 (E)** 아이디어를 한 줄씩 적으면,
Claude API가 그 자리에서 스킬 설계도를 만들고 게임이 바로 그 스킬로 플레이됩니다.

## 실행

Node.js 18 이상만 있으면 됩니다 (설치할 패키지 없음).

```bash
# 1) API 키 넣기 — 둘 중 하나
export ANTHROPIC_API_KEY=sk-ant-...        # 환경 변수
# 또는 이 폴더에 api_key.txt 파일을 만들고 키 한 줄 저장

# 2) 서버 켜기
node server.js
# → http://localhost:8080 을 브라우저로 열기 (전체화면 F11 추천)
```

옵션

| 환경 변수 | 기본값 | 설명 |
|---|---|---|
| `PORT` | `8080` | 포트 |
| `ANTHROPIC_MODEL` | `claude-sonnet-5-5` | 더 빠른 응답이 필요하면 `claude-haiku-5-5` |

- API 키는 **서버에만** 있고 브라우저로 안 나갑니다.
- 서버 콘솔에 체험자가 적은 문장과 만들어진 스킬 이름, 걸린 시간이 한 줄씩 찍힙니다.
- **프리셋 스킬 101종** (기본 공격 30 · 스킬1 35 · 스킬2 36 — 일회용 "기가 돼지" 포함): "AI로 만들기"를 누르면 체험자 문장과 가장 가까운 프리셋이 **바로** 카드에 뜨고,
  그사이 AI가 **체험자 문장만 보고 처음부터** 새 기술을 만들어 도착하면 카드가 바뀝니다 (카드 오른쪽 위: 프리셋 / 프리셋 → AI가 새로 만드는 중 / AI).
  프리셋은 AI에게 보내지 않습니다 (보내면 AI가 프리셋을 베껴 오는 문제가 있었음).
  AI를 기다리지 않고 바로 출전해도 됩니다 (그때는 프리셋으로 플레이).
- 칸을 비워 두면 AI 호출 없이 프리셋에서 고릅니다. **⚡ 빠른 시작** 버튼은 세 칸 모두 랜덤 프리셋 (최근에 나온 건 덜 나오게 순환).
- 키가 없거나 인터넷이 끊기면 프리셋만으로 동작합니다 (키워드 매칭 + 문장 속 숫자만 반영). 화면 오른쪽 위 배지로 상태 확인 가능.

## 부스 흐름

1. 아무 키 → 메뉴 → **시작**
2. 세 칸에 아이디어 적기 (예시 버튼 / "예시로 채우기" 가능, 비워 두면 AI가 알아서)
3. **AI로 만들기** → 프리셋 카드 3장이 즉시 뜨고 AI가 새로 만든 기술이 오는 대로 바뀜. 마음에 안 들면 카드별 "다시 만들기" (또는 ⚡ 빠른 시작)
4. 출전할 곳 선택: 1~5 스테이지 (4 = 종지기, 5 = 목사 → 눈)
   → 출전할 때마다 **그림으로 된 조작법 안내**(이동 · 공격 · 스킬 · 막기/패링 · 구르기 · 목표)가 먼저 뜹니다. 클릭 · 아무 키 · 터치로 시작, 18초 지나면 자동 시작. 체험자가 만든 기술 이름과 아이콘도 그 안에 나옵니다.
5. 목사(눈)를 쓰러뜨리면 결과 화면 → **다음 사람 · 새 기사 만들기**
6. 기술 만들기 화면을 4분 동안 아무도 안 만지면 입력이 자동으로 비워집니다.

## 조작

| | PC | 모바일 (가로) |
|---|---|---|
| 이동 | WASD | 왼쪽 스틱 |
| 기본 공격 | 왼쪽 클릭 | ATK |
| 스킬 1 / 2 | Q / E (또는 1 / 2) | S1 / S2 |
| 막기 · 패링 | 오른쪽 클릭 유지 / 타이밍 | BLK |
| 구르기 | Space | ROLL |
| 일시정지 | Esc | II |

난이도는 메뉴 → 설정 → 난이도 에서 바꿀 수 있습니다 (부스는 쉬움 추천).

## AI가 만드는 것 (안전장치)

AI는 코드를 쓰지 않고, 정해진 부품으로 조립한 **설계도(JSON)** 만 만듭니다. 그래서 어떤 문장을 넣어도 게임이 깨지지 않습니다.

- 동작 13종: 투사체 · 베기 · 폭발 · 낙하(운석/번개/고드름) · 돌진 · 광선 · 장판 · 회전체 · 연쇄 번개 · 소환(자동 사격) · 강화 · 회복 · 소환수(12종 그림: 돼지·강아지·늑대·고양이·곰·유니콘·드래곤·닭·골렘·슬라임·유령·개구리 · 적을 쫓아가 공격 · 살아 있는 동안 적들의 어그로가 소환수로 쏠림(기사가 공격 길목에 서 있으면 기사가 대신 맞음) · 체력 기본 2000 · 피해량 제한 없음 · 시간 무제한 가능)
- 일회용 스킬: 스테이지당 한 번만 쓸 수 있음 (쿨타임 대신). 다음 스테이지 · 재도전 때 다시 충전
- 효과 9종: 화상 · 중독 · 둔화 · 빙결 · 기절 · 넉백 · 끌어당김 · 흡혈 · 폭발
- 기본 공격: 칼질 스타일 5종(균형/묵직/빠름/찌르기/휩쓸기) + 맞을 때 효과 + 휘두를 때 함께 날아가는 것
- 모양 16종 · 색 · 효과음은 아이디어에 맞춰 AI가 고름
- **피해량 상한 없음**: "999999 데미지 화살"이면 그대로 999999. (너무 약한 공격형만 조금 올려 줌) 보스(종지기·목사·눈)는 기절/빙결/넉백에 걸리지 않고, 눈 보스 2페이즈 진입 같은 연출은 그대로 지켜집니다.
- **AI 결과 검사 (server.js)**: AI는 맨 앞 확인 칸 3개(read_check · visitor_words · scene)를 반드시 채워야 하고, 서버가 결과를 검사합니다.
  프리셋/예시 이름 그대로 · 체험자 단어가 이름·설명에 없음 · 체험자가 말한 숫자가 설계도에 없음 · 말한 동물과 소환수 그림이 다름 → 이유를 붙여 **자동으로 한 번 다시** 시킵니다 (콘솔에 "규칙 위반 → 재요청" 표시).
- **"나쁜말은 안돼"**: 지나친 욕설 · 인종차별 · 정치 · 실존 인물 공격 · 심각한 비하 · 학살 · 실제 살인 · 성폭력이 들어오면 AI가 그 칸을 고정 스킬 "나쁜말은 안돼"로 바꿉니다
  (화면이 꽃동산 동화나라로 변하고, 적들을 하나씩 꼭 안아서 집으로 돌려보냄 · 보스는 안아 주기 + 사랑의 피해). 카드에는 체험자가 쓴 문장 대신 "(나쁜 말은 꽃으로 바꿨어요)"가 표시됩니다.
  오프라인일 때는 최소한의 금칙어 목록으로만 검사합니다.

## 파일

```
index.html      게임 전체 (프리셋 101종 포함, 2장만 남긴 버전 + AI 스킬 엔진 + 기술 만들기 화면)
server.js       정적 파일 서버 + Claude API 중계
assets/audio/   음악 · 효과음
```

원본에서 빠진 것: 1장(숲 · 스토커 소리 파일), 3장(바다 전체), 튜토리얼 진입, 샌드박스,
오프닝 만화(1장 · 2장), 화형대 · 마녀 · 가문의 비법서(검기), 돈가방 연출(목사 허리 주머니 · 승리 후 가방 줍기 · 금화 쏟아짐).
마지막 스테이지 이름은 "제단"으로 바꿈.

## API 보호 (축제 운영용)

- 서버는 기본으로 **이 컴퓨터(127.0.0.1)에서만** 접속됩니다. 태블릿·폰을 같은 와이파이로 붙이려면 `HOST=0.0.0.0 node server.js`.
- 한도: IP당 분당 `PER_IP_PER_MIN`(30) · 서버 켠 뒤 총 `TOTAL_CAP`(3000)회. 넘으면 자동으로 프리셋 모드(배지가 "키 없음"으로 바뀜).
- 정적 파일은 `index.html` + `assets/` 오디오만 공개 (server.js · api_key.txt 등은 어떤 주소로도 안 나감).
- 이름(도메인)으로 들어오는 접속은 거부. 필요하면 `ALLOWED_HOSTS=booth.local`.
- **키는 환경 변수로 넣고 api_key.txt는 쓰지 마세요.** 이 폴더를 압축·공유·git에 올릴 때 키가 딸려 갑니다.

## API 키를 인게임으로 넣기 (파일·환경변수 없이)

1. `node server.js` 실행 (키 없이) → 서버가 켜진 컴퓨터에서 `http://localhost:8080` 열기
2. 주소창에 **`http://localhost:8080/admin`** 입력 → 키 입력 → **연결** (가장 확실한 방법)
   - 게임 화면에서는 **Ctrl+Alt+K** 또는 부스 화면 오른쪽 위 AI 배지 클릭으로도 열립니다.
3. 서버가 Anthropic에 무료 호출(모델 목록)로 키를 검증한 뒤 **서버 메모리에만** 저장합니다.

- 입력칸은 전송 즉시 비워지고, 브라우저(localStorage·쿠키)와 디스크에는 아무것도 남지 않습니다.
- 서버를 끄면 사라집니다. 그 전에 지우려면 같은 창에서 **키 지우기**.
- 자동 삭제: 기본 12시간 뒤 (`KEY_TTL_HOURS=0`이면 자동 삭제 없음).
- 키 입력·삭제는 서버가 켜진 컴퓨터에서 `localhost`로 열었을 때만 됩니다 (태블릿·폰에서는 불가).
- 부스 손님이 같은 화면을 만질 수 있으면 `ADMIN_PIN=원하는숫자 node server.js` 로 켜세요. PIN 없이는 키를 넣거나 지울 수 없습니다.
- 인게임 키가 있으면 환경변수/api_key.txt 보다 우선합니다.
